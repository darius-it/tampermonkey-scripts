# tampermonkey-scripts
Collection of useful Tampermonkey scripts

## Scripts

- [Moodle short course names ](https://github.com/darius-it/tampermonkey-scripts/raw/refs/heads/main/moodle-short-names/script.user.js) - Simple script to allow renaming and reordering courses in the Moodle sidebar. Currently only compatible with the UR instance of Moodle 4.5.
